# Problem Sets

Each problem set has its own folder with the PDF, the LaTeX source, and any data you need.

## How to submit

Each group has **one private repository for all of Part I**. Only your group, the TA, and I can see it.

1. Accept the GitHub invitation to the **epge-classes** organization. It's in your email and at <https://github.com/orgs/epge-classes/invitation>.
2. Open the [**assignment link**](https://classroom50.org/epge-classes/econometrics-fgv-2026/assignments/ps/accept). One member creates the group, then adds the other members.
3. Do `Assignment-00` first: every member pushes a file with their name, which checks that everyone can push.
4. Problem Set N goes in the `Assignment-0N` folder. What is on the `main` branch on GitHub at the deadline is what gets graded.

The repository's README explains how to clone it and push.
